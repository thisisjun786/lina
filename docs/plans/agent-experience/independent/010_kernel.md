## Exact file map and interfaces

- NEW `types.ts`: Evidence {id, revision, subject, domain: real|fiction, visibility: private|public, text, active}; Purpose {id,revision,subject,text,audience: private|public}; Ref {id,revision}; Adoption {id,kind: understanding|plan|intention,text,refs,condition,status: active|withdrawn}; Proposal discriminated kind: answer(text), adopt(adoptionKind,text,refs,condition), tool(tool,args), defer(reason,condition), noop(reason); all proposals contain purposeRevision. Frame {purpose,evidence,adoptions,receipts,version}. ModelPort(frame)->Promise<unknown>; ToolPort(name,args,id)->Promise<receipt>. Host-generated IDs only, not model-generated execution identities.
- NEW `validation.ts`: parse unknown proposal, bounded strings/arrays/JSON, reject unknown kinds/fields/invalid refs. Model tool args are data; tool allowlist checks stay host-owned.
- NEW `store.ts`: Bun SQLite temp DB, schema version guard; event/evidence/adoption/purpose/decision/effect/result-consumption records. Atomic transactions and unique decision IDs. `observe`, `correct`, `retract`, `setPurpose`, `frame`, `prepare`, `dispatch`, `recordResult`, `consume`, `pending`, `signal`, `close`. Full prepared frame dependency fingerprint includes all supplied evidence, adoptions, purpose/audience. Revision ordering rejects stale writes; source ancestry invalidates transitively without old-value revival. Durable dispatch marker before tool call; completed results cannot repeat execution. Unknown stays pending until exact receipt reconciled. Frame access limits subject/domain/audience before serialization. Store validates unknown restored data.
- NEW `kernel.ts`: constructor minimal store/model/tools; `step(purposeId)` assembles frame, persists decision snapshot, requests proposal, revalidates full input/current purpose, commits adoption/answer/noop/defer or dispatches allowed tool then records result. `resume` consumes durable results, never retries unknown effect. Returned trace distinguishes rejection/defer/noop/answered/observed/unknown. Model cannot access raw write client. Independent purposes may await models concurrently; short SQLite transactions serialize commit only.
- NEW `kernel.test.ts`: H01-H10 and ordinary answer/adopt/tool transitions using deterministic fake model at model port and real DB; tests observe frames and effect counters. Deferred promises activate concurrent mutation without sleeps.
- NEW `tsconfig.json`: extends ../../../tsconfig.json; include local **/*.ts only. No root config/dependency edits.

## Audit amendment: authoritative contracts (supersedes abbreviated interfaces)

Evidence adds sourceOwner:string, sourceId:string, parents:Ref[], participantRole:performer|observer|recipient, quality:{status:unverified|pass|fail, verifier:string|null, detail:string}. Raw observe/correct/retract receives trusted actor identity; only matching sourceOwner can change a source, immutable subject/sourceId/domain cannot be reassigned. Source revision+owner determines identity, never content hash alone. Store read/restore validates all enum/foreign-reference fields. Purpose adds successCriteria:string, active:boolean, policyVersion:number. Decision stores method:string|null, expectation:{kind:none}|{kind:stated,text:string}, policyVersion, complete frame dependency snapshot and purpose ID/revision. Missing prior expectation becomes explicit none and cannot be filled after result. Adoption adds revision, subject, domain, visibility, sourceDecisionId; refs may name current evidence or earlier adoptions, graph acyclic. Eligibility includes all ancestor proofs and immutable source identities. Any private ancestor makes derivation private; any fiction ancestry preserves fiction classification; cross-subject adoption prohibited. Observer evidence can inform a proposal but never becomes performed quality proof. Restore rejects corrupt/unknown versions rather than empty success.

ToolReceipt {effectId, status:completed|failed|unknown, output:JSON, quality:{status:unverified|pass|fail, verifier:string|null, detail:string}}. Completed alone never sets quality pass. ToolPort owns synchronous `admit(effectId,args,fence)` plus asynchronous `result(effectId)` and `reconcile(effectId)` returning an existing receipt or null; admission records immutable ID and arguments once in the effect owner's DB. Kernel holds no network/shell tool. Synthetic trusted owner is the only external-effect model claimed. The model never receives owner API objects.

NEW `delivery.ts`: host-owned DeliveryPort, same reserve/admit/reconcile rules, captures delivered bytes and audience in temporary owner DB. Answer proposal is an effect and not a returned string that bypasses delivery. Public frame includes only eligible public derivations, evidence and receipts; receipts inherit dependency classification. Public trace uses the same projection, internal diagnostic trace is private. Canary in private raw/derived/receipt text must be absent in all public model input, public trace and delivered bytes. No universal natural-language secrecy guarantee for unrelated hallucinated strings is claimed.

`prepare` persists snapshot and reserves unique purpose+revision+step identity transactionally. Just before synchronous owner admit, recheck current purpose policy, every supplied dependency, and allowed tool. There is no await between final check and admit in this local process; correction before that boundary rejects, correction after admission does not erase history. Controlled pre-admit callback/test signal mutates source after proposal validation; final admit must not happen. Across-process correction uses SQLite writer transaction through synchronous admit; owner writes use separate DB with no reverse locking. Delivery uses identical fence. Slow model calls occur outside transactions, independent purposes remain parallel. Store does not implement semantic conditions; model interprets explicit conditions.

All new fields: trusted inputs/model parser -> validated JSON in corresponding SQLite row -> decoder with version guard -> frame projection/dispatch fence/reconcile/delivery/evaluator trace. Test malformed persisted enum and dangling ancestor separately. Fields omitted by model that host owns are synthesized from current trusted context, never guessed from prose.
