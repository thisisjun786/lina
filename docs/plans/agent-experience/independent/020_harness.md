# Raw transport and matched evaluator

Depends on kernel D. Main writes files below, disjoint from kernel executor. NEW `model.ts`: plain HTTP Ollama chat request using existing authorized endpoint/key injected from environment; explicit model ID verified from live catalog, no agent framework, implicit history, memory or fallback. Return response content and usage, record redacted metadata and errors. Timeout is failure, never fake model output. Response parser consumes message.content and structured usage. Wire-format compatibility is checked against existing source/actual endpoint before B.

NEW `scenarios.ts`: seeded synthetic generators for B01-B15; each returns private evaluator truth separately from public input/events/tools. Generator uses shuffled labels, numbers and phrasing; no row IDs/answers in input. Tools operate on test-owned data; independent arithmetic/coverage truth stays outside model. Same generated case reused for all three modes. Multi-turn experience has source outcome then new task; normal raw history accessible in baseline.

NEW `score.ts`: exactly thirty IDs, six category aggregation, critical gating, missing row/incomplete run rejection and paired usage/delta. Expectations read fixture truth, not kernel helper results. NEW `runner.ts`: baseline/kernel/ablation sessions; same model/system action schema/limits/tool env; output traces include all requests/results/calls/failures. Freeze input manifest per run and use external artifact root. NEW `cli.ts`: --help, --mode compare|kernel|baseline|ablation, --seed, --output, --qualify (three fresh batches); mandatory explicit endpoint/model environment. NEW `harness.test.ts`: transport mock HTTP decode/failure without live default, scorer negative controls and missing-data failures, baseline parity of raw info/tools/budgets, ablation preserves raw evidence and removes derived only.

Each B row uses deterministic answer/action assertions grounded in generated data; semantic claims receive independent human/agent review of sampled raw outputs. No LLM-as-judge self-awarded scores. If unambiguous machine scoring cannot represent a row, freeze its explicit independent review procedure before scored use; cannot silently count a keyword.

Commands: focused suite/typecheck/lint and CLI --help; transport smoke uses the authorized GLM endpoint with one synthetic input and records returned model/request labels separately from backend-identity claims. D passes exact runner entry and verified provider config names to recovery.
