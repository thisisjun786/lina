## 검증 범위

- 최종 source-bound 전체 검사: `4b496d4`, **3,684 pass / 47 skip / 0 fail**, 523파일, 20,818 assertions. 기본 suite의 skip은 실제 모델 성공으로 계산하지 않는다.
- 같은 수정 이후 `LINA_LIFE_NATIVE_TEST=1 LINA_AUTHOR_NATIVE_TEST=1 bun test packages/lina-codex`: **268 pass / 0 fail**, 실제 native 프로세스와 합성 provider로 격리·복구를 검사했다.
- 타입·lint·CI 설정·빌드 검사 통과. lint의 기존 경고는 남아 있다.
- 실제 Ollama: Quick DeepSeek Flash의 관찰 저장, Deep DeepSeek Pro의 근거 기반 추론 저장, Standard GLM Flash의 요약·일반 대화·LIFE 게시, Intensive GLM의 정식 관찰 입력 파싱을 확인했다.
- 실제 컨텍스트: 요약2회·재시작2회·정정 전후 회상·원문 확장 도구 호출. 실제 자료: 의미 검색·공유 읽기·비공개 전환 후 차단. 실제 페르소나: 성향 저장·정체성 보존·근거 철회·재열기. 실제 LIFE: 공개 자료→모델→게시 저장→피드→재열기→결과 재생.
- 최종 독립 검토 PASS. 초기 지적 중 native `off` 기본값 승격을 수정했고, Quick/Deep 증거 누락 지적은 최신 저장 결과 확인 후 철회됐다.

세션 증거는 `.codexclaw/evidence/01a08149-2fcd-7b83-b427-a104f083df05/`에 있다. `acceptance-full-test-receipt.json`, `native-all-final.log`, `acceptance-final-review.md`, `world-port-current-comparison.json`, `ollama-routing/*.json`이 각 범위를 기록한다. 원문 사용자 데이터 대신 격리된 합성 입력과 임시 DB를 사용했다.

## 사용자 평가와 후속 전달

실제 모델 검증은 명시한 합성 사례의 기능 증거다. 일부 추론 모델은 작은 출력 상한에서 잘려 테스트용 예산을 늘렸다. 모든 모델·모든 예산 조합의 성능이나 장기 대화 품질을 보증하지 않는다. `reasoning: off`는 LINA의 effort override 생략이며 backend 추론 비활성을 보장하지 않는다.

다음 단계는 사용자의 장기 대화 평가와 [081](081_contract_inventory.md)을 바탕으로 한 UI 기획이다. 배포와 기존 설치 데이터 변경은 별도 요청에 따른다. 세계 설정·주기·예산·이미지/UI 제품 결정은 이번 인수에서 임의로 확정하지 않았다.
