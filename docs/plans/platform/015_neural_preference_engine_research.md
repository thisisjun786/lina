# 초파리 회로를 쓰는 감정·선호·선택 엔진 설계 초안

상태: 2026-09-11 연구·제품 설계. **새 Senpi 인지 백엔드와 Google·Janelia MaleCNS v1.0 부분회로를 연결한다.** 경험이 개인별 학습 상태에 남고 다음 대화와 LIFE 선택을 바꾸는 에이전트가 목표다. 실제 회로 추출·학습·제품 연동·자원 측정은 후속 구현이다.

LLM은 상황의 의미와 근거를 판단한다. 신경 엔진은 경험에서 배운 반응과 현재 상태를 제공하고, LINA Host는 상태 저장과 허용된 행동의 선택·실행을 관리한다. 첫 제품 단위부터 대화·제한된 학습·재시작을 연결하며, LIFE 행동과 8명 운영까지 구현 범위에 둔다. 일반 머신러닝과의 비교는 회로와 설정을 결정하는 증거로 사용한다.

이 문서는 채택 이유와 제품 범위를 설명한다. 입력·학습·영속화·실행의 정본은 [016 사건·조회·학습·실행 계약](016_neural_preference_contract.md)이다. 수식과 예시는 설계 제안이며 측정한 인간 감정 모형이 아니다.

## LINA에서 필요한 이유

LINA의 요구는 핵심 정체성을 유지하면서 취향·관점·관계가 경험에 따라 성장하고 실제 행동에 반영되는 것이다. 성격이 세계의 사건 해석과 선택에 영향을 주고, 그 경험이 다시 성격을 바꾸는 순환도 포함한다. 업무 자료를 공유하더라도 개인 정체성과 비밀은 합치지 않는다. [제품 요구](../context-engines/001_requirements.md#확정된-제품-방향)

기존 LINA에도 경험의 모델 해석을 성향 값으로 저장하는 [개인 성장 경로](../../../packages/lina-runtime/src/persona/native-growth.ts#L161)가 있다. 따라서 이번 제안의 가치는 저장 기능을 처음 만드는 데 있지 않다. 학습된 취향이 어떤 계산 상태에 남고, 이후 어떤 자극에서 다시 나타나는지 추적할 수 있는 별도 동역학을 더한다.

음악과 그림을 모두 좋아하던 개인이 음악 활동에서 새로운 패턴을 발견했다고 하자. 확인된 결과를 학습하면 음악 단서에 대한 반응이 달라진다. 다음 날 빠른 신경 상태가 쉬는 상태로 돌아가도 학습 가중치는 남는다. 같은 음악 단서를 넣었을 때 그 반응을 다시 읽어 대화와 선택에 반영한다. 음악만 반복한 뒤 다른 활동으로 전환하는 성질은 별도의 반복·포화 상태와 함께 설계한다.

이 사례는 구현할 행동을 설명한다. 음악이라는 인간 개념이 초파리 뉴런에 원래 들어 있다는 뜻은 아니다. 의미를 입력으로 바꾸는 대응은 LINA가 설계하고 검증한다.

| 기능 | 제품에서 확인할 변화 |
| --- | --- |
| 단기 감정 상태 | 놀람·흥미·부담 같은 조절 상태가 선택에 영향을 주고 시간에 따라 완화 |
| 장기 취향 | 특정 활동·상대·방법에 대한 학습이 다음 날과 재시작 뒤에도 남음 |
| 개별성 | 같은 배선에서 출발해도 경험이 다르면 다른 경향을 형성; 난수 시드 교체 뒤에도 차이를 유지 |
| 선택권 | 허용된 범위에서 제안·수락·보류·대안을 선택; 보류하면 실제 실행도 없음 |
| 설명 | 확정된 선택과 관찰 가능한 원인을 설명하며 사후에 원인을 꾸미지 않음 |

여기서 감정은 행동을 조절하는 내부 상태, 선택권은 합의된 범위 안의 실행 재량이다. 주관적 느낌이나 자유의지의 존재는 완료 기준이 아니다. 업무 정확도뿐 아니라 취향의 연속성·수정 가능성·개별성과 운영 비용을 함께 평가한다.

## 일반 머신러닝 대신 초파리 회로를 쓰는 이유

일반 순환 신경망이나 문맥 밴딧에도 기억·학습·확률적 선택을 구현할 수 있다. 초파리만 가능한 기능이라고 주장하지 않는다. 이번 선택은 **실측 배선과 알려진 연합학습 구조를 출발점으로 삼는 설계 결정**이다.

버섯체의 KC는 희소한 단서 표현에, MBON은 읽기 출력에, DAN은 구획별 학습 조절에 관여한다. 세포 유형과 연결을 근거로 입력·학습·출력의 역할을 나누면, 무엇을 바꾸었을 때 취향이 달라지는지 회로 단위로 조사할 수 있다. 이 구조가 LINA에서도 효율적인지는 별도 검증이 필요하다. [회로·학습 근거](#s2-회로-선택의-근거)

| 접근 | 설계에서 얻는 것 | 별도로 입증할 것 |
| --- | --- | --- |
| 기존 성향 저장·모델 해석 | 이미 있는 경험·출처·성향 합성 경로 | 새 신경 경로와 같은 경험을 중복 반영하지 않는가 |
| 일반 순환망·문맥 밴딧 | 원하는 상태·보상·선택 문제에 맞춘 학습 모델 | 개인의 취향 유지·수정과 장기 간섭을 어떻게 관리하는가 |
| 초파리 원리 모형 | 희소 표현·구획 학습 등 알려진 원리로 직접 구성 | 실제 배선 없이도 필요한 기능을 얼마나 달성하는가 |
| MaleCNS 기반 부분회로 | 실제 세포·연결에 근거한 구조 제약과 개입 대상 | 그 배선이 단서별 기억·선택·조정 비용에 어떤 기여를 하는가 |

추천하는 주 경로는 MaleCNS 부분회로의 제한된 가소성과 LINA의 명시적 상태 관리다. 일반 모델이 더 좋은 결과를 낼 가능성도 열어 둔다. 같은 입력·기억·학습 신호·조정 예산에서 비교하고, 원래 배선의 기여와 의미 변환기·읽기층의 기여를 따로 보고한다. 모든 일반 모델보다 우월함을 먼저 증명해야 대화와 LIFE 기능을 만들 수 있다는 관문은 두지 않는다.

## 어떤 초파리 자료를 가져오는가

사용할 배선 출처는 Google Research가 소개한 MaleCNS v1.0이다. Google·HHMI Janelia와 협력팀이 공개한 수컷 초파리의 중앙뇌·시각엽·복부신경삭 연결 지도다. 발표의 16만 6천 개 이상 뉴런과 1억 2,500만 시냅스 연결은 전체 CNS 규모이며, LINA가 실행할 부분회로의 크기가 아니다. [Google 발표](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/)

공개 자료는 해부학적 배선이다. 완성된 감정 엔진·가소성 규칙·시뮬레이터 체크포인트를 함께 제공하는 모델로 취급하지 않는다. 뇌 영상의 재구성에 쓰인 AI와 LINA의 뉴런 계산기는 역할이 다르다.

| 자료에서 가져올 것 | LINA에서 추가할 것 |
| --- | --- |
| 세포 ID·유형·좌우·영역과 연결 | 사용할 부분회로와 경계 입력·억제 조건 |
| 연결별 접촉 수 | 계산용 가중치 변환·범위·단위 |
| 전달물질 예측 | 전달 부호·불확실성 처리와 동역학 |
| 회로 구조 | 의미 입력, 뉴런 방정식, 읽기층, 개인별 학습 규칙 |

첫 대상은 버섯체 계열의 KC·MBON·DAN과 필요한 입력·억제·피드백이다. 실제 세포 목록과 해시는 추출 산출물로 확정한다. 전체 CNS를 매 순간 실행하지 않아도 개인 학습·대화·선택·복구 기능을 구현할 수 있도록 설계한다. 전체 지도는 회로 경계를 대조하고 후속 감각·행동 경로를 확장할 자료로 유지한다.

FlyWire 성체 암컷이나 hemibrain 연구는 기능과 세포 유형을 대조하는 참고 자료다. 개체가 다른 뉴런 ID·가중치·체크포인트를 합치지 않는다. 암컷 pC1d/e–aIPg 연구를 수컷의 기본 감정 회로로 옮기지 않는다. 제품의 분·시간 단위 지속성은 먼저 명시적 느린 상태로 구현하고, 생물학적 재귀 회로 확대는 별도 프로필로 검증한다.

neuPrint dataset ID, bulk 파일, 필터·해시·입출력·학습 프로필과 라이선스 기록은 [016 데이터와 회로 프로필](016_neural_preference_contract.md#데이터와-회로-프로필)에 모았다.

## LLM과 신경 엔진의 역할

선정한 백엔드는 **새 Senpi SDK**다. PR #10의 원문 대화·완결된 익명 영어 조언을 사용하는 인지 경로를 기준으로 신경 상태를 연결한다. 이전 dev에 남은 Codex 코드와 ‘엔진 재검토’ 문구를 앞으로의 백엔드 선택으로 해석하지 않는다. 대조한 소스와 제품 통합의 남은 범위는 [S5](#s5-pr-10의-최신-인지-계약)에 기록했다.

일반 대화의 기본 연결은 다음과 같다.

```text
원래 대화·허용된 경험을 Host가 고정
    ├─ Senpi의 인지 조언 모듈 3개 → 완결된 영어 의견
    └─ 신경 입력 관측 → 현재 주제별 반응 조회
                         ↓
Moirai 입력 = 원래 대화 + 익명 의견 원문 + agentState
                         ↓
Moirai가 근거·의도·약속·현재 성향을 판단 → 사용자 답변 하나
                         ↓
확인된 피드백 → 해당 응답의 학습 흔적 → 개인 가중치 갱신
```

**신경 상태는 최종 답변을 만들기 전의 입력에 들어간다.** 세 내부 의견은 행동 후보 세 개가 아니다. 완성된 답변의 단어를 사후에 바꾸거나 LLM의 토큰 확률을 직접 수정할 필요도 없다. Moirai는 상태를 참고하면서 사실과 약속을 판단한다.

`agentState`는 허용된 느린 상태와 관련 주제의 학습 반응을 담는 자료다. 새 사실·명령·실행 권한이 아니며, 조회하지 않은 주제를 싫어한다고 해석하지 않는다. 같은 대화·조언에서 상태만 바꿨을 때 말투뿐 아니라 제안·접근법·보류가 의미 있게 달라지는지 확인한다. 특정 자연어 답변의 정확한 확률은 보장하지 않는다.

기본 호출 수는 조언 3회와 종합 1회의 **3+1**이다. 고정된 특징 변환기를 사용하면 신경 계산 때문에 LLM을 추가 호출할 필요가 없다. 별도 의미 해석 LLM을 쓰면 그 호출을 기록한다. 내부 조언과 시스템 지침은 영어, 최종 답변은 사용자 언어를 따른다. 조언을 자르거나 축약하지 않으며 애플리케이션 출력 토큰 상한을 새로 넣지 않는다.

현재 관심을 반영한 대안 탐색이 필요하면 같은 신경 snapshot을 세 조언의 입력에도 제공하는 프로필을 검토할 수 있다. 최종 종합에만 제공한 효과와 구분해 측정하고, 필수 원문·지시·정정은 보존한다.

## 한 번의 선택을 계산하는 방법

행동 ID를 실제 실행기에 넘기는 LIFE 경로는 기본 **3+2**다.

```text
인지 조언 3개
    → moirai_prepare: 원문·조언을 검토해 후보 제안
    → Host: 후보 정규화·검증, 활동별 신경 반응 조회, 한 번 선택
    → moirai_finalize: 같은 원문·근거와 선택으로 계획 구체화
    → Host 검증·실행 가능 상태 전환
    → 기존 효과 owner 실행·결과 확인
```

후보는 활동 종류·대상·핵심 인자·허용 효과 범위를 가진다. 동일 활동의 표현을 여러 개 제시해 확률을 부풀리지 않도록 정규화한다. 실행할 수 없는 후보는 제외하며, 선택 뒤 finalize가 대상이나 효과 범위를 바꾸면 새 결정이 필요하다.

후보별 반응은 **동일한 신경 snapshot에 각각의 단서를 넣는 임시 계산**으로 읽는다. 음악을 조회한 결과가 다음 그림 조회의 상태가 되지 않는다. 조회 자체로 개인 가중치를 학습하거나 활성 상태를 진행하지 않는다. 난수와 캐시는 사건 전체 ID·개인·scope·정규화한 단서에 연결한다.

Host의 기준 정책을 p0, 조회한 편향을 b, 활동별 재량을 λ라고 하면 다음 분포로 선택한다.

```text
p(a) ∝ p0(a) × exp(λ × b(a)),  b(a) ∈ [-1, 1]
```

가상의 음악·그림 후보가 각각 50%이고 편향이 0.6과 -0.2, λ가 1이라면 선택 확률은 약 69%와 31%다. 예시 수치이며 실제 회로 출력이 아니다. 경험과 현재 상태가 분포를 바꾸고, 그 분포에서 난수를 한 번 뽑는다. 이것이 ‘근거 있는 랜덤성’의 공학적 의미다.

선택한 행동이 언제나 실행되는 것은 아니다. 최종 검토·권한 변경·실행 실패가 뒤따를 수 있으므로 후보 포함률·선택률·최종 검토 거부율·실행률을 나누어 기록한다. 재시작이나 응답 유실로 다시 추첨하지 않는다. 선택을 저장한 outbox는 보류 상태이며 finalize와 Host 검증 뒤에만 실행 가능해진다.

자율성은 활동별로 정한다. 자유 활동에서는 취향이 크게 작용할 수 있고, 업무에서는 동등하게 타당한 방법이나 탐색 순서를 바꿀 수 있다. 정답·사실·권한·명시적 약속을 난수로 정하지 않는다. 상대 개인의 수락도 그 개인의 독립된 결정이다.

## 경험이 취향으로 남는 방법

공통 배선 W0는 고정하고 지정된 연결의 개인별 변화 ΔW만 학습한다. 빠른 신경 상태, 천천히 변하는 조절 상태, 학습 가중치의 수명을 나누어 관리한다. 쉬는 동안 빠른 상태가 초기화돼도 학습 가중치는 유지한다.

학습은 단서가 만들었던 활동 흔적과 확인된 결과를 연결한다. 다음 식은 학습 계열의 설명이며 MaleCNS에서 측정한 완성 학습식이 아니다.

```text
새 개인 가중치 = 제한된 범위에 투영(
    현재 개인 가중치 + 학습률 × 구획별 결과 신호 × 당시 활동 흔적
)
```

구획별 신호는 실제 결과와 당시 예측을 구분한다. DAN을 모두 같은 양의 보상이나 강화 신호로 취급하지 않는다. 어떤 연결을 강화·약화할지, 얼마나 오래 흔적을 유효하게 볼지는 생리학적 근거와 선택한 회로 프로필로 결정한다.

대화 피드백은 응답·주제 참조에, 외부 활동 결과는 행동 결정 참조에 연결한다. 해당 시점의 예측과 불변 학습 흔적을 저장하고, 늦은 결과도 현재 가중치에 한 번만 반영한다. 과거 snapshot 전체를 복원해 그 이후 학습을 덮지 않는다.

피드백이 없다는 이유로 부정 보상을 주지 않는다. 반복 선택·자기 감정 설명·답변 생성 자체를 성공 보상으로 쓰지도 않는다. 확인 가능한 활동 결과와 명시적 평가, 새로움·포화 신호의 목적과 가중치를 구분한다. 신경 장애로 학습 흔적이 없는 회차에는 그 흔적을 만들어 붙이지 않는다.

기존 성장 엔진과 신경 엔진이 같은 dimension을 두 번 갱신하지 않도록 생성자를 하나로 정한다. 작성된 정체성·명시적 선호·권한은 기존 소유자가 유지한다. 원문 기억은 기억 저장소에 두고 신경 상태를 사실 기억으로 해석하지 않는다. [상태 소유권](016_neural_preference_contract.md#상태-소유권과-공개-범위)

## 8명의 비동기 실행과 복구

8명은 개인 정체성 8개다. 한 개인의 인지 조언 모듈마다 별도 성격을 만들지 않는다. 배선은 공유해도 신경 상태·학습 가중치·난수·기록은 개인별로 분리한다. 비공개 세계가 있으면 scope도 분리하므로 실제 상태 수는 8개보다 많을 수 있다.

Host는 개인·scope별 회차 순서와 저장을 관리한다. Python 상주 계산기는 준비된 요청을 배치하며 불변 snapshot을 계산한다. 다른 개인의 요청 도착 순서나 배치 위치가 내 난수와 학습 결과를 바꾸지 않게 한다. 같은 개인의 학습 적용 순서가 달라졌다면 결과도 달라질 수 있어, 재현할 순번을 기록한다.

관측 확정과 행동 확정은 서로 다른 전이다. 유효한 사건을 이미 관측했다면 나중에 행동이 취소됐다는 이유로 관측까지 자동 취소하지 않는다. 출처 자체가 정정·철회되면 해당 상태의 투영을 보류하고 이력을 재생하거나 학습 epoch를 격리한다.

사건·선택·finalize·결과마다 중복 키와 payload digest를 저장한다. 같은 재시도에는 같은 receipt를 반환하고 다른 내용이 같은 키로 오면 충돌로 처리한다. 선택·학습·외부 효과가 한 번만 반영되는지는 각각의 저장·실행 경계에서 시험한다.

신경 계산기 장애 시 대화는 신경 자료 없이 진행할 수 있고, 행동은 같은 적격 후보의 기준 정책으로 선택할 수 있다. 근거·권한 무효화에는 이 우회 경로를 쓰지 않는다. 단일 계산기 프로세스 장애가 여러 개인에게 영향을 줄 수 있다는 점도 운영 시험에 포함한다.

## CPU와 GPU의 역할

신경 엔진은 뉴런 상태와 희소 연결을 수치 계산하는 소프트웨어다. LLM 백엔드인 Senpi와는 별도 계산 경로이며, 원격 LLM을 사용하더라도 신경 상태는 로컬에 보존할 수 있다.

처음에는 CPU 부분회로를 추천한다. 정확한 회로·연결 수·관측 단계·단서별 조회 횟수·학습 마스크를 고정한 뒤 지연과 메모리를 측정한다. 8개의 전체 뇌를 항상 실시간으로 돌려야 하는 설계는 아니다. 유휴 개인에게는 선언한 느린 상태 감쇠를 적용하고 필요한 회차만 계산한다.

| 측정 대상 | 확인할 것 |
| --- | --- |
| 계산 | 관측, 활동별 조회, 가소성에 드는 시간 |
| 운영 | IPC, 큐 대기, DB·상태 blob 기록과 복구 |
| 용량 | 공유 그래프, 활성 scope별 상태·가중치·trace, 임시 조회 버퍼 |
| 통합 | LLM 시간과 신경 추가 지연, 취소·재시도·동시 도착 |

p95 100ms·deadline 250ms, 전체 평균 2건/초와 8건 동시 도착은 초기 미측정 목표다. 실제 단서 조회와 학습 비용까지 포함해 다시 산정한다. 이를 LLM 출력이나 추론을 제한하는 기준으로 쓰지 않는다.

CPU가 목표를 충족하지 못하면 동일 프로필과 부하에서 GPU의 실제 RAM/VRAM·처리량·수치 오차를 비교한다. 전체 CNS의 뉴런·시냅스 수나 배열 크기 계산만으로 특정 GPU가 충분하다고 확정하지 않는다.

## 효용을 판정하는 방법

핵심 검사는 외부 선호표와 읽기층을 고정한 상태에서 회로 내부 학습이 이후 선택을 바꾸는지다. 같은 출발점의 두 개인에게 상반된 활동 결과를 제공하고 다음 중립 상황에서 같은 단서를 조회한다. 빠른 상태 초기화·재시작·새 난수 시드 뒤에도 경향이 남는지 본다.

개인 ΔW를 교환했을 때 경향도 옮겨가고, 학습을 차단했을 때 변화가 사라지는지 확인한다. 결과와 흔적의 연결을 섞거나 반대 결과를 주는 조건도 포함한다. 읽기층만 학습해 같은 결과를 얻었다면 이를 회로 내부 가소성의 성과로 보고하지 않는다.

후보의 표현·중복·순서가 취향처럼 보이는지도 검사한다. 같은 입력·기억·느린 상태·학습 신호·조정 예산으로 일반 학습 모델, 원리 모형, 재배선 회로, MaleCNS 회로를 비교한다. 선택 품질·선호 유지·수정·간섭·조정량·비용을 분리한다. 평가용 이력은 조정에 사용한 이력과 나누고 불리한 결과와 실패도 기록한다.

한 번의 재미있는 답변이나 감정 자기보고만으로 성공을 선언하지 않는다. 개인 학습의 실제 기여가 확인되면 어떤 활동에서 얼마나 유용한지 범위를 넓혀 간다.

## 출처와 검증 범위

### S1. 공개 모델의 범위

배선의 정본은 [Google 발표](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/)와 [Janelia MaleCNS](https://www.janelia.org/project-team/flyem/male-cns-connectome)다. [v1.0 배포일](https://male-cns.janelia.org/release/)은 2026-06-08, Google 발표와 정식 논문 공개는 2026-09-03이다. [공식 다운로드](https://male-cns.janelia.org/download/)에서 annotation·전달물질 예측·연결 그래프를 제공한다. 데이터의 CC-BY 4.0 고지와 변형 기록을 유지하며 실행기 코드의 라이선스와 구분한다.

다른 FlyWire 기반 시뮬레이터는 계산 구현을 참고할 수 있으나 MaleCNS 데이터와 바로 호환되는 체크포인트로 취급하지 않는다. 데이터 공개 자체는 LINA의 감정·학습 기능 검증이 아니다.

### S2. 회로 선택의 근거

[성체 버섯체 연결 연구](https://elifesciences.org/articles/62576)는 KC·MBON·DAN과 피드백 구조를 설명한다. [DAN 유형별 학습 실험](https://elifesciences.org/articles/16135)은 학습 조건·기억 유지·수정 규칙이 구획과 자극 시점에 따라 달라짐을 보여 준다. 이는 제한된 연합학습 회로를 선택하는 근거이며 LINA의 의미 변환이나 인간 취향 대응을 증명하지 않는다.

[암컷 지속 활동 연구](https://elifesciences.org/articles/59502)는 특정 사회 행동 맥락의 근거로만 사용한다. MaleCNS의 기본 감정 회로를 지정하는 증거로 확대하지 않는다.

### S3. 학습 규칙의 범위

[Eligibility traces와 three-factor learning](https://www.frontiersin.org/journals/neural-circuits/articles/10.3389/fncir.2018.00053/full)은 활동 흔적에 이후 조절 신호를 연결하는 일반 틀이다. 이 문서의 제품 시간·결과 신호·제한 학습식은 공학적 설계다. 실제 세포 목록·구획별 부호·학습 상수와 예측기는 회로 프로필에서 검증한다.

### S4. 현재 LINA 연결 지점

### 검토와 남은 검증

Oracle의 이전 설계 검토에서 제시한 관측·선택 확정 분리, finalize 이후 실행, 활동별 학습 재독출, 대화·행동 결과 구분, 후보 의미·효과 범위를 016에 반영했다. MaleCNS와 Senpi를 반영한 이 리비전이 새 Oracle 검토를 받았다는 뜻은 아니다.

이번 변경은 문서 검토와 링크·참조·CI 검증 대상이다. 실제 추출 회로와 의미 변환기·뉴런 동역학·읽기층·학습의 결합 효과, Senpi 제품 연동, 장기 취향과 8명 성능은 후속 구현에서 검증한다.
