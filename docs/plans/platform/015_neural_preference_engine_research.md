# 모이라이 엔진의 근거와 출처

상태: 2026-09-12. 정본 [MOIRAI_ENGINE](../../MOIRAI_ENGINE.md)이 확정한 설계의 제품 요구, MaleCNS 선택 이유, 자료 출처, 계산 자원 방향, 효용 판정 방법과 1차 문헌을 소유한다. 모듈 정의·조정 정책·catalog·의도 schema·회로 프로필 인터페이스는 정본이, 계약은 [016](016_neural_preference_contract.md)이, 로드맵은 [017](017_moirai_module_composition.md)이 소유한다. 이 문서의 문헌 연결은 공학적 설계 판단의 근거이며, 논문 이름을 붙였다는 이유로 세 관점의 우월성이나 회로의 효용을 확정하지 않는다.

## LINA에서 필요한 이유

LINA는 핵심 정체성을 유지하면서 취향·관점·관계가 경험에 따라 성장하고 실제 행동에 반영되기를 요구한다. 성격이 사건 해석과 선택에 영향을 주고 그 경험이 다시 성격을 바꾸는 순환도 포함한다. 업무 자료를 공유해도 개인 정체성과 비밀은 합치지 않는다. [제품 요구](../context-engines/001_requirements.md#확정된-제품-방향)

이미 [개인 성장 경로](../../../packages/lina-runtime/src/persona/native-growth.ts#L161)가 경험을 해석해 성향 값을 저장한다. 엔진은 이 기반에 예측·선호·의도를 계산하는 구조를 연결한다. 어떤 경험이 무엇을 바꿨고 그 변화가 다음 선택에 어떻게 작용했는지 추적하는 것이 목표다.

| 제품 목표 | 확인할 행동 |
| --- | --- |
| 경험과 성장 | 확인된 결과가 다음 예상·선호·접근법을 바꾸고 정정된 경험은 수정 가능 |
| 가치와 선택 | 관심·취향·목표·약속이 충돌할 때 근거를 비교해 제안·수락·보류·대안을 선택 |
| 개인의 연속성 | 회차·모델 세션·재시작이 바뀌어도 정체성·학습·진행 의도가 유지 |

이 표는 LINA 전체의 결과를 확인하는 기준이다. 각 모듈에는 [정본의 고유 목표](../../MOIRAI_ENGINE.md#세-판단-모듈)를 각각 부여하며, 세 목표를 모든 모듈의 공통 최적화 목표로 재배분하지 않는다. 여기서 감정은 행동을 조절하는 내부 상태, 선택권은 허용된 범위의 실행 재량이다. 주관적 느낌이나 자유의지를 완료 기준으로 두지 않는다.

한 개인이 공유하는 코어 기능은 정체성·자기모델, 상황 이해, 기억·경험, 정서·동기·선호, 목표·의도·약속, 추론·계획·선택, 학습·자기점검의 일곱 가지다. 이 일곱 기능은 공동 기반이며 일곱 서버·LLM·DB를 요구하지 않는다. 기존 Memory·Persona·Resource·World/LIFE 소유권은 [정본의 배치 표](../../MOIRAI_ENGINE.md#기존-모듈의-배치)에 따라 재사용한다.

## 라케시스에 MaleCNS를 쓰는 이유

일반 순환 신경망이나 문맥 밴딧에도 기억·학습·확률적 선택을 구현할 수 있다. 초파리만 가능한 기능이라고 주장하지 않는다. 이번 선택은 **실측 배선과 알려진 연합학습 구조를 출발점으로 삼는 설계 결정**이며, 정본 D14에 따라 엔진 완성의 필수 요소다.

버섯체의 KC는 희소한 단서 표현에, MBON은 읽기 출력에, DAN은 구획별 학습 조절에 관여한다. 세포 유형과 연결을 근거로 입력·학습·출력의 역할을 나누면, 무엇을 바꾸었을 때 취향이 달라지는지 회로 단위로 조사할 수 있다. 이 구조가 LINA에서도 효율적인지는 별도 검증이 필요하다. [회로·학습 근거](#s2-회로-선택의-근거)

| 접근 | 설계에서 얻는 것 | 별도로 입증할 것 |
| --- | --- | --- |
| 기존 성향 저장·모델 해석 | 이미 있는 경험·출처·성향 합성 경로 | 새 신경 경로와 같은 경험을 중복 반영하지 않는가 |
| 일반 순환망·문맥 밴딧 | 원하는 상태·보상·선택 문제에 맞춘 학습 모델 | 개인의 취향 유지·수정과 장기 간섭을 어떻게 관리하는가 |
| 초파리 원리 모형 | 희소 표현·구획 학습 등 알려진 원리로 직접 구성 | 실제 배선 없이도 필요한 기능을 얼마나 달성하는가 |
| MaleCNS 기반 부분회로 | 실제 세포·연결에 근거한 구조 제약과 개입 대상 | 그 배선이 단서별 기억·선택·조정 비용에 어떤 기여를 하는가 |

주 경로는 MaleCNS 부분회로의 제한된 가소성과 LINA의 명시적 상태 관리다. 일반 모델이 더 좋은 결과를 낼 가능성은 비교 실험으로 확인한다. 같은 입력·기억·학습 신호·조정 예산에서 비교하고, 원래 배선의 기여와 의미 변환기·읽기층의 기여를 따로 보고한다. 모든 일반 모델보다 우월함을 먼저 증명해야 대화와 LIFE 기능을 만들 수 있다는 관문은 두지 않는다.

## 어떤 자료를 가져오는가

사용할 배선 출처는 Google Research가 소개한 MaleCNS v1.0이다. Google·HHMI Janelia와 협력팀이 공개한 수컷 초파리의 중앙뇌·시각엽·복부신경삭 연결 지도다. 발표의 16만 6천 개 이상 뉴런과 1억 2,500만 시냅스 연결은 전체 CNS 규모이며, LINA가 실행할 부분회로의 크기가 아니다. [Google 발표](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/)

공개 자료는 해부학적 배선이다. 완성된 감정 엔진·가소성 규칙·시뮬레이터 체크포인트를 함께 제공하는 모델로 취급하지 않는다. 뇌 영상의 재구성에 쓰인 AI와 LINA의 뉴런 계산기는 역할이 다르다.

| 자료에서 가져올 것 | LINA에서 추가할 것 |
| --- | --- |
| 세포 ID·유형·좌우·영역과 연결 | 사용할 부분회로와 경계 입력·억제 조건 |
| 연결별 접촉 수 | 계산용 가중치 변환·범위·단위 |
| 전달물질 예측 | 전달 부호·불확실성 처리와 동역학 |
| 회로 구조 | 의미 입력, 뉴런 방정식, 읽기층, 개인별 학습 규칙 |

첫 대상은 버섯체 계열의 KC·MBON·DAN과 필요한 입력·억제·피드백이다. 실제 세포 목록과 해시는 추출 산출물로 확정한다. 전체 CNS를 매 순간 실행하지 않아도 개인 학습·대화·선택·복구 기능을 구현할 수 있도록 설계한다. 전체 지도는 회로 경계를 대조하고 후속 감각·행동 경로를 확장할 자료로 유지한다.

FlyWire 성체 암컷이나 hemibrain 연구는 기능과 세포 유형을 대조하는 참고 자료다. 개체가 다른 뉴런 ID·가중치·체크포인트를 합치지 않는다. 암컷 pC1d/e–aIPg 연구를 수컷의 기본 감정 회로로 옮기지 않는다. 제품의 분·시간 단위 지속성은 먼저 명시적 느린 상태로 구현하고, 생물학적 재귀 회로 확대는 별도 프로필로 검증한다.

neuPrint dataset ID, bulk 파일, 필터·해시·입출력·학습 프로필과 라이선스 기록은 [016 데이터와 회로 프로필](016_neural_preference_contract.md#데이터와-회로-프로필)에 모았다.

## CPU와 GPU의 역할

신경 엔진은 뉴런 상태와 희소 연결을 수치 계산하는 소프트웨어다. LLM 백엔드인 Senpi와는 별도 계산 경로이며, 원격 LLM을 사용하더라도 신경 상태는 로컬에 보존할 수 있다.

처음에는 CPU 부분회로를 사용한다. 정확한 회로·연결 수·관측 단계·단서별 조회 횟수·학습 마스크를 고정한 뒤 지연과 메모리를 측정한다. 8개의 전체 뇌를 항상 실시간으로 돌려야 하는 설계는 아니다. 유휴 개인에게는 선언한 느린 상태 감쇠를 적용하고 필요한 회차만 계산한다.

| 측정 대상 | 확인할 것 |
| --- | --- |
| 계산 | 관측, 활동별 조회, 가소성에 드는 시간 |
| 운영 | IPC, 큐 대기, DB·상태 blob 기록과 복구 |
| 용량 | 공유 그래프, 활성 scope별 상태·가중치·trace, 임시 조회 버퍼 |
| 통합 | LLM 시간과 신경 추가 지연, 취소·재시도·동시 도착 |

p95 100ms·deadline 250ms, 전체 평균 2건/초와 8건 동시 도착은 초기 미측정 목표다. 실제 단서 조회와 학습 비용까지 포함해 다시 산정한다. 이를 LLM 출력이나 추론을 제한하는 기준으로 쓰지 않는다. CPU가 목표를 충족하지 못하면 동일 프로필과 부하에서 GPU의 실제 RAM/VRAM·처리량·수치 오차를 비교한다. 전체 CNS의 뉴런·시냅스 수나 배열 크기 계산만으로 특정 GPU가 충분하다고 확정하지 않는다.

## 효용을 판정하는 방법

| 확인할 원인 | 통제한 개입과 관찰 |
| --- | --- |
| 전망·계획 계산 | 목표와 선호를 고정하고 외부 근거를 바꿔 클로토의 예측·계획 수정과 실제 예측 오차를 확인 |
| 경험·가치 계산 | 같은 입력·readout에서 상반된 경험 또는 개인 ΔW 교환/차단. 라케시스 평가와 다음 선택 경향이 움직이는지 확인 |
| 의도·연속성 계산 | 같은 경험·예측에서 수락한 약속·기한만 변경. 아트로포스의 충돌 판단·재계획·실행 조건이 바뀌는지 확인 |
| 조정 정책 | 같은 후보를 `user_request`·`autonomous`·`transition`으로 돌려 D17의 순서·`λ`가 선언대로 적용되는지, 약속 보호가 취향 반대와 구분되는지 확인 |
| 목표와 메커니즘의 기여 | 같은 LLM·원문·기억·총자원에서 동일 목표 3+1과 고유 목표 3+1을 비교. 고유 목표를 유지한 프롬프트 방식·전체 구조·메커니즘 제거군도 별도로 비교 |

먼저 동일 사실에서 목표가 충돌하거나 일치하는 사례로 각 모듈의 고유 목표에 따른 추천을 확인한다. 합의율·최종안 채택을 세 모듈의 공통 성공 보상으로 쓰지 않는다. 모듈 단독 시험에서는 다른 입력을 고정해 원인을 확인하고 통합 시험에서는 그 변화가 후보 생성·선택·결과로 전파되는지 본다. 모든 모듈이 서로 다른 답을 내는 비율을 성능으로 삼지 않는다. 목표 지속·선호 유지/수정·사실 정확도·실제 실행 결과·총비용을 각각 기록한다.

회로는 빠른 상태 초기화·재시작·새 난수 시드 뒤에도 학습 경향이 남는지 검사한다. trace와 결과의 연결을 섞는 조건, 무보상·반대 결과, 외부 readout만 학습하는 조건도 포함한다. 일반 순환망/밴딧·원리 모형·재배선·MaleCNS를 같은 입력·학습 신호·조정 예산으로 비교해 배선의 기여를 분리한다.

후보 표현·중복·순서, 평가 누락·예산 소진, 선호의 이중 가산과 source/약속 변경도 반례에 넣는다. 조정용 경험과 평가용 경험을 분리하고 실패를 누락하지 않는다. 모델의 감정 자기보고나 사후 설명으로 판단·학습 성공을 채점하지 않는다. 구체적인 가설 표는 [017](017_moirai_module_composition.md#검증할-가설과-반례)에 있다.

## 출처와 검증 범위

### S1. 공개 모델의 범위

배선의 정본은 [Google 발표](https://research.google/blog/a-connectomics-milestone-mapping-the-complete-male-fruit-fly-brain/)와 [Janelia MaleCNS](https://www.janelia.org/project-team/flyem/male-cns-connectome)다. [v1.0 배포일](https://male-cns.janelia.org/release/)은 2026-06-08, Google 발표와 정식 논문 공개는 2026-09-03이다. [공식 다운로드](https://male-cns.janelia.org/download/)에서 annotation·전달물질 예측·연결 그래프를 제공한다. 제공자가 연결한 [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/) 고지와 변형 기록을 유지하며 실행기 코드의 라이선스와 구분한다.

다른 FlyWire 기반 시뮬레이터는 계산 구현을 참고할 수 있으나 MaleCNS 데이터와 바로 호환되는 체크포인트로 취급하지 않는다. 데이터 공개 자체는 LINA의 감정·학습 기능 검증이 아니다.

### S2. 회로 선택의 근거

[성체 버섯체 연결 연구](https://elifesciences.org/articles/62576)는 KC·MBON·DAN과 피드백 구조를 설명한다. [DAN 유형별 학습 실험](https://elifesciences.org/articles/16135)은 학습 조건·기억 유지·수정 규칙이 구획과 자극 시점에 따라 달라짐을 보여 준다. 이는 제한된 연합학습 회로를 선택하는 근거이며 LINA의 의미 변환이나 인간 취향 대응을 증명하지 않는다.

[암컷 지속 활동 연구](https://elifesciences.org/articles/59502)는 특정 사회 행동 맥락의 근거로만 사용한다. MaleCNS의 기본 감정 회로를 지정하는 증거로 확대하지 않는다.

### S3. 학습 규칙의 범위

### S6. 전망·의도·종합의 계산 근거

| 1차 자료 | 가져오는 원리 | LINA 적용의 범위와 한계 |
| --- | --- | --- |
| [ReAct, 2022](https://arxiv.org/abs/2210.03629) | 추론·행동·관측을 연결하며 계획을 갱신 | 클로토의 예상과 도구 관측을 연결한다. 해당 논문이 LINA의 비용 예측이나 장기 계획 정확성을 보장하지 않음 |
| [SayCan, 2022](https://arxiv.org/abs/2204.01691) | 언어로 그럴듯한 행동과 로봇이 수행할 수 있는 skill을 함께 고려 | 의미 제안과 도메인 가능 조건의 분리를 참고한다. 작성된 World 규칙 검사는 논문의 학습된 로봇 가치 함수와 같지 않음 |
| [Rao·Georgeff의 BDI, 1995](https://cdn.aaai.org/ICMAS/1995/ICMAS95-042.pdf) | 정보·동기·채택된 의도, 제한된 자원에서 의도 유지와 재고 | 아트로포스의 지속·완료·전제 변경 시 재고에 적용한다. 세 BDI 개념을 모이라이 세 모듈과 일대일 대응시키거나 LLM의 합리성을 입증한 것으로 보지 않음 |
| [Mixture-of-Agents, 2024](https://arxiv.org/abs/2406.04692) | 여러 제안자의 결과를 다음 종합 단계의 입력으로 사용 | 세 완결된 판단과 종합을 잇는 실행 골격을 참고한다. 서로 다른 판단 메커니즘·개인 학습·선택권의 효용은 이 논문의 결과와 별도로 검증 |
| [Ensemble 공식 문서](https://github.com/ensemble-engine/ensemble/wiki) | 작성된 규칙에서 사회적 의향·행동·효과를 계산 | 기존 vendored 어댑터를 사회 도메인 서비스로 재사용한다. 범용 세계 예측기·신경 학습기·독립 인격으로 취급하지 않음 |

위 연결은 공학적 설계 판단이다. 예측 가능한 도메인 규칙, 수락된 의도, 출처 있는 경험을 실제 판단 입력과 결과에 연결하려는 선택이며, 논문 이름을 붙였다는 이유로 세 관점의 우월성을 확정하지 않는다. 같은 총자원의 단일 판단·역할 프롬프트 방식과 비교하고, 모듈 하나의 상태를 바꾸는 개입으로 기여를 확인한다.

### 검토와 남은 검증

이 세 판단 구조는 새 설계이며 이전 신경 모듈 초안의 Oracle 검토 결과를 승계하지 않는다. 문서·링크·CI 검증은 설계의 일관성을 확인한다. 실제 회로·의미 변환·뉴런 동역학·학습의 결합 효과, 세 판단의 추가 효용, Senpi 제품 통합과 장기 운영은 후속 구현에서 검증한다.
