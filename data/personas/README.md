# Character presets

These nine presets derive from the maintainer-provided `lina-persona` collection.
Its authored preset text, including the imported SOUL and CHARACTER documents,
is covered by Lina's [Apache-2.0 license](../../LICENSE) and
[contributor attribution](../../NOTICE). Third-party material retains its own
terms. User-created profiles and private runtime data are outside this source grant.

## Source records and local modifications

[sources.json](sources.json) contains 18 document records. `source` is a portable
lineage identifier of the form `lina-persona/agents/<character>/<document>`; it
identifies an input in the original collection, not a file or public URL in this
checkout. `file` is relative to the Lina repository root. `sha256` preserves the
recorded original import digest; `currentSha256` identifies the current bytes at
`file`. An original hash is provenance, not a claim that the original repository
is publicly available or that every local document is unchanged.

`sources/lina-SOUL.md` includes local authored changes. Its original import digest
is `fb39e3b4a17ea6b294125fbcf7b3c6df3d0dfde530f0f7dc007068da205c1f7f`;
its current digest is
`b26bc705d11f889b4fdf05281111342b26fea48f9bad94f5d0255eb9a8c03049`.
`sources/sion-SOUL.md` and its matching preset profile generalize personal fleet
names to the user’s computers, servers, storage and agent runtimes. The authored
privacy edit preserves technical responsibilities and permission boundaries; its
original digest remains in `sha256` and its updated digest in `currentSha256`.
All nine CHARACTER documents retain character roles, voice and appearance while
replacing private image-production history and unavailable source-collection links
with the shipped avatars. Kanna’s SOUL, CHARACTER and matching preset use the
user’s chosen name/address instead of a personal name. Each authored edit is
described in `sources.json`. Six unmodified SOUL digests match their originals;
Lina, Sion, Kanna and the nine CHARACTER files have local modifications. Future
edits must update `currentSha256` and describe the change while retaining
`sha256`. Image bytes and their attestation are unchanged.

## Runtime use

`presets.json` is the editable seed, not a runtime database. Only Lina is created
by default; other presets become agents when the user adds them. Existing agents
are never overwritten when the seed changes. Runtime profiles and growth live in
`LINA_HOME/state/agents.sqlite` (default `~/.lina/state/agents.sqlite`), with
separate fixed sessions under each agent root. Explicit legacy state paths remain supported.

- Core: name, work, personality, voice. Only the user edits these.
- Interests: authored interests plus bounded interests learned through repeated turns.
- Temporary mood: based on the conversation, expires after4 hours.
- Learned preferences and relationship style: bounded, traceable, reversible. Each
  kind retains16 recent confirmed entries, replacing the oldest when a new one is confirmed.
- Profile/appearance: character lore, only read on demand, excluded from normal prompts.

The prompt compiler emits a bounded JSON character capsule each turn. Character
fields and memory grant no additional permissions. Tool results/assistant claims
are not independent evidence of lived experience. There are no autonomous wakeups.
